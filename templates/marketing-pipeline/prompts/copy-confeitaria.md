# Prompt — Copy confeitaria (tom de marca)

## Marca

**Açucaradas Encomendas** — conecta clientes a confeiteiros artesanais. Tom: doce, humano, confiável, sem exageros infantis.

## Entrada

```yaml
produto_destaque: brigadeiro gourmet
ocasiao: aniversário infantil
limite_palavras: 400
```

## Instruções

1. Headline emocional (máx. 12 palavras).
2. Subheadline com benefício claro (entrega, artesanal, app).
3. 3 bullets de benefícios para o **comprador**.
4. 1 parágrafo curto para o **produtor** (vender pelo app).
5. Microcopy para botão WhatsApp (máx. 4 palavras).
6. Evitar: "o melhor do Brasil", "nº 1", claims não verificáveis.
7. Incluir 2 variações A/B da headline.

## Saída

Markdown com secções nomeadas + tabela A/B.
